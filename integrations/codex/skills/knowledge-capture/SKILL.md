# 知识提炼与候选生成

遵循安装位置同一 Codex home 下的 [KNOWLEDGE.md](../../KNOWLEDGE.md)。由智能体结合当前任务、已有知识和后续复用场景，自主判断内容是否具有沉淀价值，综合考虑信息增量、复用收益与证据充分性，并明确区分已验证事实和待验证判断。

1. 先从已核实结果提炼可复用结论、条件、取舍、反例、排障方法和验证边界；只读审查、设计和已验证失败也覆盖。无知识要点时说明具体原因，不作空检索。有要点时用 knowledge_recall：按 Recall Skill 提炼同一知识目的的 queries 表达数组，仅选择必要且已获授权的 capabilityIds；GLOBAL 用 []。不默认全选范围。
2. 比较实质相关正文：有持久 recallItemId 时据此 asset_read，否则用 assetId + expectedContentHash 读当前内容。已有检索与正文充分时复用，不为流程重复读取。摘要不是全文，无命中不是无历史。
3. 比较结论、适用条件与证据，判断新增、扩展/修订、无增量或暂不能判断。无增量须说明具体依据：已核对的 Asset 完整覆盖且条件/边界未变；仅执行哪项已确定要求且未形成新判断；为何只是不可复用的临时状态；或指出权威原文及章节，核对内容完整、后续正常发现路径和另存无收益。仅“项目文档已写”“测试通过”“只是重构”“没有搜到”均不足以成立。只有当前链接、目录索引或未来可全文搜索，不自动证明发现路径充分；有独立召回价值时提炼简短 MEMORY 引用原文，或按现有 DOCUMENT 整理导读，不复制全文。关键证据或访问缺口属暂不能判断，继续主任务；不通过 Hub、直接文件路径或自填 Workspace 绕过访问边界。
4. 只有获授权且值得沉淀时，在已确认目标 Workspace 的 Inbox 准备候选。访问能力不是文件写入授权；只读、禁止知识写入或目标不清楚时仅展示建议。按 KNOWLEDGE.md 中的明确链接读取知识内容模型，不按当前业务仓库解析模板路径。
5. 新增用共享 Asset ID；修订保留 ID，记录当前正式基线原始字节 SHA-256，生成合并后完整正文。保留当前源事实和历史差异，不覆盖正式 Asset。
6. 重读候选，保留路径、Asset ID 和原始字节 Hash；修订另保留正式基线 Hash 与必要 Diff。按知识内容模型统一展示候选及增量理由，不另定展示字段。确认须绑定展示时的完整内容与 Hash，内容或基线变化须重新展示。
7. 接受后按 KNOWLEDGE.md 的链接读取 README 确认参数，重读核 Hash，再执行当前单文件 asset:confirm；修改按具体意见重写并重新展示；暂存只保留候选；拒绝只在明确删除授权且路径/Hash核对一致时删除本次候选。不新增候选催办、账本或迁移旧知识；仅使用下面已安装的本轮短记录和非阻断检查。
8. 检查 usageRecorded；检索失败计数不妨碍评估已返回内容，但无稳定引用不得 Used 或补账。只有知识实质影响工作才按使用结算协议标记；比较本身不自动算 Used。
9. 工程任务附带的候选随主任务结果展示，未收到反馈也正常完成主任务交付，之后再处理用户的明确意见。仅在用户明确要求当场审阅知识时进入对应反馈步骤，不用等待工具维持附带候选的选择框。

## 本轮短结果

工程交付前，在最后一次影响结论的工作或验证之后，用宿主 UserPromptSubmit 提供的 `command`，通过 stdin 提交 JSON：`sessionId`、`turnId`、`outcome`、非空 `reason`，以及按需 `references`（字符串数组，候选路径与 Hash、Asset 或具体只读建议位置）。总输入不超过 8 KiB。通过带引号的 heredoc 或结构化文件传参，避免 shell 展开正文。不要自行编造标识、复用旧轮标识或把 capabilityId 填进记录。

- `NO_INCREMENT`：已评估，理由满足第 3 步。
- `CANDIDATE`：已准备新增/修订候选，或明确只读时已形成具体建议；必须有引用。仅有准备意向或准备失败用 FAILED。待正式确认不妨碍完成。
- `FAILED`：评估或必要核对未完成，写明具体缺口；不能冒充无增量。
- `SKIPPED`：本轮有工具活动，但实际仅澄清、进度等非工程交付，说明原因。普通无工具交流不调用 CLI。

之后若有新需求、修改或证据影响结论，重新评估并覆盖本轮结果；评估记录和 Used 结算本身不递归评估。宿主未提供标识/命令或记录失败时，如实说明记录不可用，继续交付。Stop 仅对可观察活动的遗漏、无效记录或 FAILED 提醒，允许结束，不替代评估、不自动补跑。记录只证明声明已提交，内容质量仍须按上述标准判断。
