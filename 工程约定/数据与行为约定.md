# 数据与行为约定

适用于 Asset、Task、Loadout、Usage、知识访问和持久化相关修改；仅按本次主题读取。本文细化根目录 AGENTS.md，不扩大实施或真实数据操作授权。

- `assets/` 是正式 Asset，`inbox/` 是待确认候选。扫描正式索引时不得纳入 Inbox；候选文件只能在人工明确确认后进入正式区。
- 单文件确认绑定确切相对路径与预期内容 Hash，保留冲突检测和禁止覆盖的语义；普通实现或测试授权不等于对真实候选的确认授权。
- Frontmatter 只能按 YAML 数据解析，复用 `asset/frontmatter.ts`；不允许文件选择可执行解析器。`contentHash` 是原文件实际字节的 SHA-256，不规范化换行、Unicode 或 YAML 顺序。
- 保留目录、Frontmatter、Workspace 配置一致性和 Symlink 拒绝规则。资格无法确定时不输出受保护内容；Catalog 命中、旧 Hash 或历史 Loadout ID 都不能替代当前文件资格。
- Task Workspace 从可信 Hook cwd 和配置解析；按路径段边界取最长匹配，无匹配得到 `null`，同等最长匹配歧义拒绝。MCP 从 Task 派生 Workspace，不接受调用者任意指定 Workspace 越权。
- Task 上下文为 `null` 时只允许 GLOBAL；非空时允许 GLOBAL 与对应 Workspace。当前 Asset 是 GLOBAL 或单一 WORKSPACE，不擅自扩展成多 Workspace 模型。
- Hub/REST 的个人本地库浏览与 MCP 的 Task 上下文访问是不同契约；不能把 Hub 的浏览能力直接用作模型读取权限，也不能未经需求把 Hub 强制绑定 Task。
- Loadout 通过显式操作更新；Hook 读取已保存装配，不自动 Resolve 或刷新。历史选择与当前输出资格分别校验；资格拒绝、可选知识故障和输出预算降级不能混为同一语义。
- Recall、Read、Used 含义分别保留；不得从搜索、读取或装配自动推断 Used。调整失败处理时核对内容返回与 Usage 写入各自的成功边界。
- Catalog/FTS 是派生数据；Task、Usage 和已保存 Loadout 是运行数据。索引修复/重建不得顺带删除运行数据，也不得以整库重置掩盖失败；运行数据可清空不代表已获清空授权。
- Hub/REST 保持只读，MCP 按既有工具提供受限写入；本地 Server 保持回环监听及现有 Host/Origin 检查。对外暴露、迁移、全局 MCP/Hook 配置变更不属于普通实现授权。
