构建 smoke 要求 `CODEX_MEMORY_OS_SMOKE_BUILD_ROOT` 为隔离构建绝对路径，其下有 `apps/server/dist` 和 `apps/hub/dist`。Server ESM 构建需要可解析工作区依赖，并在构建根提供 `type: module`；本次只将依赖目录链接到隔离构建，没有执行 install。构建分别使用 tsc `--outDir` 与 Vite `--outDir` 指向这两个目录。

```bash
CODEX_MEMORY_OS_SMOKE_BUILD_ROOT='/absolute/isolated-build' \
  pnpm --filter @codex-memory-os/server exec node test-support/recall-runtime-smoke.mjs
```

该脚本自行创建临时知识文件、数据库与配置，使用临时端口，结束后清理数据。Hook 输入为 fixture 模拟的可信宿主事件，不能算真实 Desktop 能力交付验收。
