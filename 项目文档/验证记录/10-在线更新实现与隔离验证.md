# 在线更新实现与隔离验证

日期：2026-09-12。范围：个人 macOS App 0.2.0 的应用内检查、下载和安装重启，以及本机安装包与公开更新包的分离。未上传 GitHub Release、未替换当前 `/Applications` 应用。

## 实现与取舍

- 原生应用菜单增加“关于”和“检查更新”。固定查询公开仓库 `hemuzzz/CodexMemoryOS` 的最新稳定 Release；按数值比较版本，相同或更低版本不安装，发布标签、清单、架构和文件名须一致。
- 本机 `security find-identity -v -p codesigning` 返回无可用签名身份。未使用要求签名的 Electron/Squirrel 自动更新器，也未关闭系统安全设置。个人实现使用固定仓库 HTTPS、受限 CDN 重定向、大小及 SHA-256 校验；这不等于 Apple 签名或公证。
- 校验通过的 DMG 只读挂载，检查 App 符号链接闭合后复制到临时目录。用户选择“安装并重启”后，将当前已安装的更新器复制到独立临时目录，由现有普通 Node 执行；不依赖开发环境的 packager/pnpm。
- 安装器验证版本、buildId、架构、Bundle ID，复用原有互斥、正常退出、旧后端归属核验、文件替换和新构建 READY 检查；不强杀进程。替换失败恢复旧程序；新版启动失败保留备份并提示，不自动降级数据库。
- 更新包不包含 `local-runtime.json` 及 pnpm 本机路径元数据。安装时保留当前本机配置，知识、数据库和工作区配置留在原处。数据库 schema 或 Hook/Skill/MCP 配套需人工处理的发布使用 `--manual-only`，只提示查看说明。
- 源码入口：[版本与下载](../../apps/desktop/src/updates.ts)、[原生更新交互](../../apps/desktop/src/online-update.ts)、[安装器](../../apps/desktop/src/update-app.ts)、[发布产物](../../apps/desktop/src/release.ts)。命令和使用入口统一见 [README](../../README.md#macos-独立-app个人本机)。
